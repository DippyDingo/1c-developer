# 1C-программист: расширенный курс

Дата прохождения: 7 апреля 2025 — 18 сентября 2026

## Структура репозитория

Каждая работа находится в отдельном тематическим блоке со своей подтемой.

## Как запустить

1. Выбрать нужный тематический блок и подтему
2. Скачать необходимый файл с расширением `.dt`
3. Открыть платформу 1С:Предприятие 8.3 (8.3.27.1606) 
4. Выбрать тестовую ИБ(Информационную базу) или Добавить новую ИБ
5. Запускаем в режиме "Конфигуратор"
6. Открываем Подменю "Администирование" - "Загрузить информационную базу" - Выбираем скачанный`File.dt`

### Требования

* 1С:Предприятие 8.3 (8.3.27.1606)
